# Changelog

## [0.2.0] - 2026-10-31

### Added

- Pandoc and/or Pdflatex related errors now appear as OS-level notifications
- `.tewii.json` files can be modified (e.g. to include new source files) and project state updated whilst the project is currently open

### Changed

- `.tex`, `.pdf` and other auxiliary Pandoc files now go into their own `out/` directory, keeping project directories cleaner

## [0.1.0] - 2026-10-27

Initial release.
